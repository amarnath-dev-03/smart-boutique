
# Smart Boutique

## Smart Tailoring & Boutique Management System

Smart Boutique is a Django-based web application designed to manage the day-to-day operations of a tailoring and boutique business.

## Features

- User Login & Logout
- Forgot Password with Email OTP
- Customer Management
- Customer Measurements
- Product Management
- Inventory Management
- Order Management
- Order Items Management
- Automatic Product Price
- Payment Management
- Expense Management
- Invoice PDF Generation
- Business Reports
- Dashboard with Charts
- Search and Filters
- PostgreSQL Database

## Technologies Used

- Python
- Django
- PostgreSQL
- HTML
- CSS
- JavaScript
- Chart.js
- Git & GitHub

## Project Modules

- Customers
- Measurements
- Products
- Inventory
- Orders
- Payments
- Expenses
- Dashboard
- Reporting
- User Authentication

## Database

PostgreSQL is used as the primary database.

## Project Purpose

This project helps boutique and tailoring businesses manage customers, measurements, products, inventory, orders, payments, expenses and business reports from a single system.
